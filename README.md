# The Inclusion Exchange

## Project Structure

## Description

This project was reorganised into a modular folder structure to improve maintainability and make it easier for future developers and interns to navigate the codebase.

### Folder Purpose

* `index.html` – Main website entry point
* `css/style.css` – Website styling
* `assets/images` – Content and section images
* `assets/logos` – Brand and partner logos
* `assets/icons` – Icon assets

## Notes

The website design, content, branding, and functionality were preserved during this refactor. Only file organisation and asset paths were updated.
